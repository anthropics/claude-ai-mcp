# Project notes

## The Growth Framework (thegrowthframework.live)

Blog for Pakistan and South Asia on Mind, Body and Money. Owner: Waseem Raja.
Instagram: @the_growth_frame_work (same handle on Facebook and Pinterest).

### Where things live
- Site source: `growth-framework/`. Static site generated by `node build.mjs` into `dist/` (no npm install needed).
- Articles: `growth-framework/src/posts.mjs` (newest first; fields: slug, pillar, date, read, title, lede, body, optional sources).
- Pillar foundation guides: `growth-framework/src/foundations.mjs`.
- Styles and browser JS: `growth-framework/src/styles.css`, `growth-framework/src/site.js`.
- Photos: `growth-framework/public/img/`. Share images: `growth-framework/public/og/` (regenerate with `node og.mjs`, needs Playwright).
- Writing rules, the editorial brief and all article templates: `growth-framework/WRITING.md`. Follow it for every new article.
- Section lists in `build.mjs`: `PATTERNS` (Breaking Patterns), `STORIES` (Success Stories series, add new parts to the end), `AI_SKILLS` (AI & Skills), `FEATURED`, `MOST_READ`, `ARTICLE_PHOTO`.

### Pages
`/` magazine home, `/framework` full framework story, `/mind`, `/body`, `/money`, `/patterns`, `/stories`, `/ai`,
`/psx`, `/guides`, `/about`, `/articles`, `/articles/<slug>`.

### Hosting and services
- Vercel project `growth-framework-blog` (root directory `growth-framework`), connected to this repo.
  Pushes to `main` publish the live site; other branches get a private preview link.
- Email sign-ups: Supabase table `public.subscribers` (insert-only for the public key). Schema in `growth-framework/supabase/subscribers.sql`.
- `drafts/` and the Vercel project `product-hunter-*` belong to a separate project; leave them alone.

### How the owner likes to work
- Changes go to a branch and a preview first. Only publish (merge to `main`) when the owner says "go live".
- Plain English, no hype, no income or health guarantees, evidence and sources for important claims,
  Pakistan context, setbacks included in success stories.
- Test before pushing: `node build.mjs`, then check pages on phone (390px) and desktop widths.

### Ideas waiting
- Success Stories: one new part a week (recent fintechs, Pakistani startups; check current facts first).
- Instagram carousel text from articles to bring readers to the site.

### Owner decisions (do not ask again)
- Scheduled routines (PSX daily brief weekdays, Success Story Mondays, pillar article Wednesdays, Instagram carousel text Fridays,
  all 8:45 to 8:55am Pakistan time) are approved to publish automatically: commit and push to `main` without waiting for "go live".
  Manual requests in a chat session still go to a branch and preview first unless the owner says otherwise.
- Use free tools for media. Skills in `.claude/skills/`: `carousel` (Instagram Carousel Engine: `/carousel [topic]`, the full carousel system, performance log in `carousel/performance.md`), `live-carousel` (every carousel slide a looping 1080x1350 video with one beat-locked song), `slides` (carousel/deck PNG + PDF, slideshow MP4 with music),
  `video-clip` (short MP4 reels from animated HTML), `framer-motion` (Motion animation, vanilla and React), `trigger-dev` (Trigger.dev background jobs, schedules and email sequences; references in the skill folder). Outputs go in `media-out/` (git-ignored).
- Music: generated `calm`/`bright` pads or tracks the owner supplies; never download unlicensed music.
- Every new article needs a share image: run `node og.mjs` after `node build.mjs`.
