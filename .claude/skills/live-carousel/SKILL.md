# Live carousel (free tools: HTML, Motion, Playwright, ffmpeg, numpy)

Instagram allows videos inside a carousel. Here each slide is its own looping MP4 (1080×1350, 4:5) and its music is the
next bars of one song, so swiping feels like one piece. No AI video model: text stays sharp, every move lands on a beat,
and changes are one line and a re-render. Plan the content with the `carousel` skill first (share-first engine, hooks,
one CTA, quality checks); this skill only makes it move.

## Make one

1. Copy `template.html` to `media-out/<slug>/deck.html` and write one `<section class="slide">` per slide.
   A slide is 2 bars (4 s at 120 BPM) by default; give longer slides `data-bars="4"` (the CTA slide, dense slides).
2. Animate in `window.__frame(i, t)`, which must draw slide `i` at `t` seconds. Build paused Motion animations once
   and set `.time = t` (as in the template), or set styles directly from `t`. Never use timers or `Date.now()`.
3. Render: `node .claude/skills/live-carousel/render-live.mjs media-out/<slug>/deck.html media-out/<slug> --music calm`
   Options: `--bpm 120`, `--bars 2`, `--fps 30`, `--music calm|bright|none|<owner's track>`.
   Output: `slide01.mp4`, `slide02.mp4`, … Upload them to Instagram as one carousel, in order.
4. Check: grab frames from each MP4 (`ffmpeg -ss 1.5 -i slide01.mp4 -frames:v 1 -vf scale=360:-1 f.png`), Read them,
   and confirm `max_volume` is below -1 dB (`ffmpeg -i slide01.mp4 -af volumedetect -f null -`). Send with SendUserFile.

## Motion rules (easing, weight, rhythm)

- Rhythm: 120 BPM = one beat every 0.5 s. Start every move on a beat (delays of 0, 0.5, 1, 1.5 s…). Slides are whole bars.
- Easing: ease-out for entrances (`[0.22, 1, 0.36, 1]`), springs only for the one key element; never linear for objects.
- Weight: big things move slowly and a short distance, small things move faster. Headline in by beat 1, support by beat 3,
  then hold so people can read. One continuous element (a ball, line or shape) that crosses every slide ties the carousel together.
- Loops: Instagram loops each slide. End each slide in a calm hold, or with idle motion whose period divides the slide length,
  so the loop point is invisible. The generated music already loops cleanly.
- Respect the brand (colours and fonts in the `slides` skill), the safe area (90 px sides, 140 px bottom) and the
  `carousel` skill's never-list: motion supports reading, it never fights it.

## Two styles

- Pure motion design (no photos, $0, cleanest): type, shapes, numbers, one travelling element. Best for teaching and frameworks.
- Bring an existing carousel to life: rebuild each slide in layers (background, cut-out photo, text, cards) as separate
  elements so each can move on its own. Use only photos the owner owns or that are free to use.

## Music

`calm` (Am-F-C-G) and `bright` (C-G-Am-F) are original songs generated by `music.py`: pad, bass and plucked arpeggio,
with drums on the middle slides so the song has an intro and outro. Each slide gets the next bars. An owner-supplied track is
cut into consecutive slide-length pieces (it will only loop cleanly if it is 120 BPM and starts on a bar). Never download music.
