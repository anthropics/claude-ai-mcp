# Slides (free tools: HTML, Playwright, Chromium)

Write the slides as one HTML file, then render each `.slide` to PNG and all slides to one PDF:

```
node .claude/skills/slides/render-slides.mjs deck.html media-out/<name> --w 1080 --h 1350
```

Sizes: Instagram carousel 1080x1350 (default), square post 1080x1080, Story 1080x1920, presentation deck 1920x1080.
Put outputs in `media-out/` (git-ignored) and send the PNGs or PDF to the user with SendUserFile.
Do not put rendered images in `growth-framework/public/` unless the user asks for them on the site.

## HTML rules

- Each slide is `<section class="slide">` with fixed `width`/`height` equal to `--w`/`--h`, `box-sizing:border-box`, `break-after:page`, and `@page{margin:0}` on the page.
- Load fonts with the normal Google Fonts `<link>`; the script serves them even though the browser has no direct internet. Use `display=block`.
- Brand (from `growth-framework/src/styles.css`): background `#0c0d10`, surface `#171a21`, text `#f0f0ec`, muted `#a2a4ad`; Mind `#a082ff`, Body `#3ddc84`, Money `#ffc454`. Headings in Bricolage Grotesque 700/800, body text in Newsreader, numbers and labels in JetBrains Mono.
- One idea per slide, a big headline (72 to 110px on 1080 wide), at most about 25 words of body text, generous padding (80 to 100px). First slide is a hook, last slide points to `thegrowthframework.live` or `@the_growth_frame_work`.
- Follow `growth-framework/WRITING.md`: plain English, no hype, no income or health guarantees, sources for important numbers.

## Slideshow video with music

After rendering, turn the slides into an MP4 with music (for Reels, Stories, WhatsApp status):

```
node .claude/skills/slides/slideshow.mjs media-out/<name> media-out/<name>.mp4 --per 3 --music calm
```

`--per` is seconds per slide. `--music` options:
- `calm` (default) or `bright`: a soft background pad generated by ffmpeg, free to use anywhere with no copyright risk.
- a path to an audio file the user supplied (mp3, wav, m4a); it loops or trims to fit, with fade in and out.
- `none`: silent.

Never download music unless the user gave it or it is clearly licensed for free reuse. If the user wants trending sounds, tell them to add the sound inside the Instagram or TikTok app after uploading.

## Check before sending

Open one or two PNGs with Read and look at them: no text cut off, nothing overflowing, readable at phone size.
For animated slides or motion, use the `framer-motion` skill; for a video, use the `video-clip` skill.
